# Прогноз урожайности дикой черники

Проектный практикум УрФУ · команда 9

Прогнозируем урожайность в кг/га на конец цветения по характеристикам участка, погоде и плотности опылителей. Работаем с [777 смоделированными сценариями](WildBlueberryPollinationSimulationData.csv).

## Результаты

| Модель | Средняя MAE, кг/га |
| --- | ---: |
| Прогноз среднего | 1 099,43 |
| Линейная регрессия на 7 признаках | 517,73 |
| Ridge без полиномов, `alpha=1` | 482,34 |
| Ridge с `GridSearchCV` | 281,14 |
| Ridge с `RandomizedSearchCV` | 270,79 |
| **Ridge с полиномом второй степени, `alpha=1`** | **259,60** |

Метрики рассчитаны на пяти внешних фолдах внутри 621 рабочей строки. Параметры подбирались на внутренних фолдах. Финальный прогон на 156 отложенных строках пока не выполнен.

## Запуск

Из корня проекта с Python 3.12 выполните команды:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Откройте [ноутбук проекта](team_9_blueberry.ipynb) в VS Code или Jupyter, выберите ядро из `.venv` и нажмите **Run All**. В ноутбуке также описан вклад каждого участника команды.
